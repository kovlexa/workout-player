# Тренировки

Персональный PWA-плеер домашних тренировок.

## Структура

- `programs.js` — циклы, разминка и сами программы тренировок. Для новых циклов в основном меняется этот файл.
- `app1.js` — каталог медиа упражнений.
- `app3.js`–`app8.js` — движок плеера: таймеры, отдых, пауза, сохранение состояния, звук и Wake Lock.
- `dashboard.js` — главный экран, история тренировок и контрольные точки прогресса.
- `sw.js` — офлайн-кэш PWA.

## Локальные данные

На устройстве в localStorage сохраняются:
- незавершённая тренировка;
- история завершённых тренировок;
- контрольные точки: вес, талия, подтягивания, отжимания и комментарий;
- настройки звука и Wake Lock.

Эти данные остаются на конкретном устройстве/в конкретном браузере и не публикуются в GitHub.

## Циклы

Текущий цикл: **Цикл 1 — Вход в форму**.

При добавлении следующего цикла старый можно перевести в статус архива, а новый отметить активным — интерфейс подхватит это автоматически.
